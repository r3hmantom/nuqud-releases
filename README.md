# Nuqud

Nuqud is a personal finance and shared-expenses app. Track your money, split bills with friends and family, and see where it all goes. It works offline, so your data stays on your phone and you do not need a connection to use it.

Website: **[nuqud.app](https://nuqud.app/)**

This page is where the Android builds are published.

## Install on Android

1. Open the [latest release](../../releases/latest).
2. Download the file ending in `-arm64.apk` (it suits almost every modern phone).
3. Open the downloaded file. Android will ask you to allow installing apps from this source (your browser or file manager). Allow it, then tap Install.

## Updates

After the first install, Nuqud updates itself. When a new version is out, the app shows an Update button. Tap it and the new version is downloaded and installed over the old one, keeping your data.
